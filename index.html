Shorts Pipeline

A private tool that publishes original animated YouTube Shorts to the owner's own channels.

Shorts Pipeline is used by one person to manage their own YouTube channels:

  • Money Bits (@TheMoneyBits): animated personal finance explainers
  • Mind Upgrade (@MindUpgradeShorts): animated self-improvement and psychology explainers
  • Clip Desk (@TheClipDeskShorts): licensed business clips

It uses the YouTube Data API to upload and schedule videos to those channels, and the YouTube Analytics API to read their performance for a private dashboard. It does not access any other user's account or data, and it is not offered to the public.
