Privacy policy

Shorts Pipeline · Last updated 11 October 2026

Who uses this app

Shorts Pipeline is a private tool used only by its owner to manage the owner's own YouTube channels. It is not available to the public.

What data it accesses

With the owner's permission through Google sign-in, the app accesses:

  • the ability to upload, schedule and update videos on the owner's YouTube channels (YouTube Data API);
  • performance reports for those channels, such as views, watch time, subscribers gained and estimated revenue (YouTube Analytics API).

It does not access any other Google data, and it does not access data belonging to anyone other than the owner.

How the data is used and stored

Channel statistics are used only to show the owner a private performance dashboard and to decide which video topics to make next. Sign-in tokens are stored as encrypted secrets in the owner's private GitHub repository. No data is sold, shared with third parties or used for advertising.

YouTube API Services

Shorts Pipeline uses YouTube API Services (the YouTube Data API and the YouTube Analytics API). By using Shorts Pipeline, users agree to be bound by the YouTube Terms of Service. YouTube is a Google service, so the Google Privacy Policy also applies to data handled through YouTube.

Shorts Pipeline's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Sharing

Data obtained through YouTube API Services is not sold, rented or shared with any third party, and is not used for advertising. It is visible only to the owner.

Cookies and device storage

Shorts Pipeline has no public user interface. It does not place cookies on users' devices and does not read or store information on users' browsers or devices.

Data retention and deletion

  • Channel statistics are kept only as long as needed for the dashboard and are refreshed at least every 30 days; data older than 30 days that has not been refreshed is deleted.
  • The owner can revoke the app's access at any time on the Google security settings page: https://myaccount.google.com/permissions.
  • When access is revoked, the stored sign-in token stops working and is deleted, and all stored YouTube API data is deleted within 30 days.
  • To ask for deletion of any stored data at any time, email the contact address below; it will be deleted within 7 days.
